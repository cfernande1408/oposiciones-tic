# Apuntes

Aquí van los apuntes por tema. Cada fichero `.md` o `.mdx` que pongas dentro de `docs/` aparece en este menú automáticamente.

Para crear un tema nuevo:

```bash
mkdir -p docs/grupo-2
cat > docs/grupo-2/t22-sgbd.md << 'MD'
---
title: "Tema 22: SGBD relacionales y SQL"
---

# Tema 22: SGBD relacionales y SQL

Tus apuntes aquí.
MD
```

Consulta el [programa completo](./programa.md) para ver la numeración de los temas, que es la misma que usan los bancos de preguntas.
